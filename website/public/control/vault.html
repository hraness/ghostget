Create a service account with read-only access to one dedicated vault. Enter its vault ID below; the next macOS prompt collects the service-account token. Local items work without 1Password.

Locking the 1Password app does not revoke service-account access. Disconnect it here and revoke its token in 1Password when it is no longer needed.

How Vault works

Local secrets are stored in macOS Keychain. Your agent can use only the grants you configure and receives results, never passwords. Browser passwords and passkeys stay with your browser or password manager; Vault does not autofill or perform unattended browser login.
