GhostGet lets an agent drive a website the way it would call an API. Instead of screenshots and clicks, it runs a named action for the site: list the inbox, send the message, pull the statement. A task that costs 36,000 tokens of browsing takes about 3,800, and the agent never holds a password.

How it works

{{PORTFOLIO_HEADING:how-it-works-heading}}

Your agent names the task, GhostGet runs one action against your signed-in session, and JSON comes back.

  1. 01
    Name the job

    Read a page, check an inbox, or save a video.

  2. 02
    Match one action

    Your agent picks one from the installed list, such as gmail messaging.list.

  3. 03
    Run it on your machine

    Against the account you connected. Account changes wait for your confirmation.

  4. 04
    Return the result

    JSON or Markdown for the agent’s next step.

Safety

{{PORTFOLIO_HEADING:local-by-design-title}}

Sign-ins and saved results stay on your machine. Actions contact only the service you choose.

Keep sign-ins local
Each connection belongs to one account; your agent receives results, never the password.
Preview account changes
A send or an edit shows you what it will do and runs after you confirm.
Keep earlier reads
Saved reads are encrypted on your machine, so a failed refresh leaves your copy in place.
Stop when a service changes
An action stops instead of guessing, and a write with an unknown result is never sent twice.

Questions

{{PORTFOLIO_HEADING:faq-title}}

Which agents does it work with?

Any agent that can run commands: Claude Code, Codex, Cursor, Gemini CLI, or your own. The optional Agent Skill teaches it the GhostGet commands and their limits in one step. A platform that exposes tools through MCP can wrap the same commands; see the agent platform notes.

Does GhostGet need an account?

Public-page reads need no account. Connect a service when you want its actions. A free Hraness account is optional and lets you manage support across our studio.

Does it use my credentials?

Yes, for connected services. Sign-ins stay in a local store and are omitted from GhostGet’s outputs. Your agent keeps any separate tools and permissions you give it.

What does it cost?

Nothing. GhostGet is free and MIT licensed, with no hosted tier and no paid plan. You pay your model provider and any service subscriptions you already have.

Which platforms does it run on?

macOS and Linux with Bun 1.3.14. Actions that read iMessage or Apple Photos need macOS. Beeper actions need Beeper Desktop on the same machine, and WhatsApp reads need a linked device.

Why does GhostGet refuse to retry some writes?

If a write went out and its result is unknown, GhostGet won’t send it again. It stays marked unsettled until separate evidence shows what happened.
