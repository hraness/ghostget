What it does

{{PORTFOLIO_HEADING:uses-heading}}

Read
Turn a public URL into Markdown your agent can inspect on the spot or keep in a local knowledge base.
Archive
Save one media item you’re allowed to access, with its transcript and source details. Playlists, live streams, and DRM-protected media are not supported.
Act
Use supported actions across {{PROVIDER_SURFACE_COUNT}} services, including Beeper, Gmail, and YouTube. Search LinkedIn and Bluesky, reply on Hacker News, X, and Substack, publish video to LinkedIn, Threads, and Substack, and run group chats. Most need a connected account.

How it works

{{PORTFOLIO_HEADING:how-it-works-heading}}

GhostGet runs supported actions and returns their results. Connect an account only when the action needs one.

  1. 01
    Name the job

    Ask your agent to read a page, check an inbox, or save a video.

  2. 02
    Match one action

    Your agent selects an action from the installed capability list.

  3. 03
    Use the right account

    GhostGet checks the selected account and inputs. Account changes require your preview and confirmation.

  4. 04
    Return the result

    Read the result, save it, or let your agent use it in the next step. Incomplete or unknown results stay visible.

Terminal controls

{{PORTFOLIO_HEADING:control-heading}}

Review connected accounts, permissions, pending approvals, recent activity, and saved output files from the terminal. Your agent reads the same state with --json.

Run ghostget status for one screen of accounts, approvals, and outputs. ghostget control serve keeps the control owner running without a window, and ghostget control install starts it at login. Every grant asks you at the terminal.

Prefer the keyboard? Run ghostget tui. Tab moves between six sections, Enter opens actions, and ? shows help. Public-page reads need neither.

Safety and limits

{{PORTFOLIO_HEADING:local-by-design-title}}

Connections and saved results stay on your machine. Actions contact the service you choose.

Keep sign-ins local
Each connection belongs to one account and service. Your sign-in stays on your machine; your agent receives the results.
Preview account changes
Review account changes before they happen, or choose which messages GhostGet may send for you.
Keep earlier reads
Saved reads are encrypted on your machine. If a refresh fails, your earlier copy is still there.
Stop when a service changes
An action stops when its service changes, so you can check what happened before trying again.

Questions

{{PORTFOLIO_HEADING:faq-title}}

Which agents does it work with?

Any agent that can run commands: Claude Code, Codex, Cursor, Gemini CLI, or your own. The optional Agent Skill teaches it the GhostGet commands and their limits in one step.

Does GhostGet need an account?

Public-page reads need no account. Connect a service when you want its actions. A free Hraness account is optional and lets you manage support across our studio.

Does it use my credentials?

Yes, for connected services. Sign-ins stay in a local store and are omitted from GhostGet’s outputs. Your agent keeps any separate tools and permissions you give it.

What does it cost?

Nothing. GhostGet is free and MIT licensed, with no hosted tier and no paid plan. You pay your model provider and any service subscriptions you already have.

Does it phone home?

The CLI sends an aggregate run report; set HRANESS_TELEMETRY=off to disable it. The SDK does not send that report. Actions, sign-in, and messaging sync contact their selected services. Supported global CLI installs also check GitHub for updates; use ghostget update disable to turn those checks off. This website uses cookieless analytics and honors Do Not Track. See privacy details.

Which platforms does it run on?

macOS and Linux with Bun 1.3.14. Actions that read iMessage or Apple Photos need macOS. Beeper actions need Beeper Desktop on the same machine, and WhatsApp reads need a linked device.

Is GhostGet an AI agent?

Your agent supplies the model and plan. GhostGet supplies the CLI, SDK, account connections, and local controls.

Does GhostGet use a browser internally?

Yes, in two cases. When a page can’t be read without rendering it, GhostGet runs its own browser, at most two at once; page reads try a single HTTP request first. Some signed-in provider actions, such as certain LinkedIn and Instagram reads, also run inside a contained browser session. In both cases the browser accepts no selectors, coordinates, or scripts from the caller.

Why does GhostGet refuse to retry some writes?

If a write went out and its result is unknown, GhostGet won’t send it again. It stays marked unsettled until separate evidence shows what happened.

What does release {{GHOSTGET_RELEASE}} include?

Page capture, media archives, encrypted reads, and {{PROVIDER_CALLABLE_ACTION_COUNT}} supported actions across {{PROVIDER_SURFACE_COUNT}} services. ghostget capabilities shows what is installed and available on your machine, and the provider list names every action in this release.
