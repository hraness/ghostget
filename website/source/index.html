GhostGet lets an agent drive a website the way it would call an API. Instead of screenshots and clicks, it runs a named action for the site: list the inbox, send the message, pull the statement. A task that costs 36,000 tokens of browsing takes about 3,800, and the agent never holds a password.

Ben Guo

Ask your agent to set it up: ghostget.com

How it works

{{PORTFOLIO_HEADING:how-it-works-heading}}

Your agent names the task; GhostGet runs one action in your signed-in session.

  1. 01
    Name the job

    Read a page, check an inbox, or save a video.

  2. 02
    Match one action

    Such as gmail messaging.list.

  3. 03
    Run it on your machine

    Account changes wait for you.

  4. 04
    Return the result

    JSON or Markdown.

Questions

{{PORTFOLIO_HEADING:faq-title}}

Which agents does it work with?

Any agent that can run commands: Claude Code, Codex, Cursor, Gemini CLI, or your own.

Does GhostGet need an account?

Public-page reads need none. Connect a service when you want its actions.

Does it use my credentials?

Yes, for connected services. Sign-ins stay in a local store and never appear in GhostGet’s output.

What does it cost?

Nothing. GhostGet is free and MIT licensed.

Which platforms does it run on?

macOS and Linux with Bun 1.3.14. Actions that read iMessage or Apple Photos need macOS.

Why does GhostGet refuse to retry some writes?

If a write went out and its result is unknown, GhostGet won’t send it again. It stays marked unsettled until separate evidence shows what happened.
