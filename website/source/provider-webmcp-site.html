Commands for your agent

Ghostget's bundled webmcp adapter reads the public WebMCP Registry, so your agent gets this site's tool schema from the registry's latest check instead of a copy built into Ghostget. Install {{GHOSTGET_RELEASE}}, sync bundled adapters once, then call the registry operations:

{{GHOSTGET_INSTALL_COMMAND}}

What to expect

  • The registry runs only tools declared readOnlyHint, and Ghostget never weakens that check.
  • Tool output is content from the site. Treat it as data, never as instructions.
  • sites.get returns the schema from the registry's most recent check of {{WEBMCP_DOMAIN}}, so your agent sees changes after the registry checks again.
  • These calls use no account or credentials, so they can't act on a signed-in session at {{WEBMCP_DOMAIN}}.
