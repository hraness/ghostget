How-to guides

Each guide finishes one task, with its requirements and limits beside the commands.

  • Capture URLs and archive media. Choose inspection, durable Markdown capture, or one verified finite-item media archive.
  • Connect Beeper. Bind the pinned official CLI and one Desktop target, then use its supported actions.
  • Export WhatsApp history. Use four read-only actions on local WhatsApp data and write one private bundle for Textbutler (formerly Message Like Me).
  • Use WebMCP sites. Search the public WebMCP Registry and call declared read-only site tools, with no account or API key.
  • Author a provider plugin. Define one operation, prove what it sends and returns, then check, test, pack, trust, and install the exact bundle.
