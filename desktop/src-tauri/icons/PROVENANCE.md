# Ghostget icon

The mark is the white 👻 emoji with its original black face and pink tongue.
PNG and ICNS files derive from the exact 160-pixel native Apple Color Emoji
bitmap; no accent recoloring is applied. The 1024-pixel PNG enlarges that
bitmap and does not add high-resolution detail.

The render uses Sharp 0.35.3 / libvips 8.18.3 from the independently verified
Slopcamera 3.2.6 distribution. Its vectorized candidate was rejected during
visual review because of faceted shading. No Slopcamera runtime or font is
bundled with Ghostget.

The shared 64-pixel mark is `desktop/assets/ghost.png`; the website uses the same
bytes plus a 32-pixel favicon. [Artifact provenance](../../assets/ghost-provenance.json)
binds the selected source, renderer, and final files. The macOS ICNS contains
explicit representations for the supported Dock and Finder sizes.
