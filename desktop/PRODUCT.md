# Ghostget control panel

This native companion lets a person connect accounts, inspect capabilities,
manage private vault items, integrations and permissions, approve bounded requests, inspect web
activity, and copy setup instructions for their own agent. The agent primarily
operates the existing CLI. The person intervenes occasionally.

The explicit brief sets macOS first, Paper appearance, eight compact navigation
sections, readable provenance, honest connection states and no agent/chat runtime.
Activity is a searchable, filtered virtual table with infinite keyset loading.
The implementation inherits the site's existing Paper visual authority; no new
brand or speculative product claim is introduced.
